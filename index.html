音OFF

One tap for Sound, Vibrate, or DND.

音OFF is a tiny Android utility for people who want a home-screen icon that changes the phone’s real sound mode immediately, without opening a full app.

Download APK Source on GitHub

Why

No dashboard.

Tap the launcher icon and the mode changes. The app exits by itself.

Real state, not a counter.

音OFF checks Android’s current ringer and DND state before deciding what to do.

Pixel-friendly.

Built around modern Android DND behavior instead of unreliable background Quick Settings cycling.

How to use

  1. Install the APK on Android.
  2. Put 音OFF on your home screen.
  3. Tap it to cycle Sound ↔ Vibrate by default.
  4. Long-press the icon and open Settings if you want to include DND or change language.
  5. If DND is included, grant Android “Do Not Disturb access” when asked.

Jak používat

  1. Nainstaluj APK na Android.
  2. Dej 音OFF na domovskou obrazovku.
  3. Klepnutím přepínáš výchozí cyklus Zvuk ↔ Vibrace.
  4. Dlouhým stiskem ikony otevřeš Nastavení, kde lze přidat DND nebo změnit jazyk.
  5. Pokud zapneš DND v cyklu, povol Android oprávnění “Přístup k režimu Nerušit”.

音OFF は、ホーム画面のアイコンを押すだけで Android の実際の音モードをすぐ切り替える小さなユーティリティです。通常のアプリ画面を開く必要はありません。

なぜ

画面を開かない。

ランチャーアイコンを押すとモードが変わり、アプリは自動で閉じます。

内部カウンターではなく実状態。

音OFF は Android の現在の着信音モードと DND 状態を確認してから切り替えます。

Pixel 向けに現実的。

不安定な Quick Settings のバックグラウンド操作ではなく、現代の Android DND 動作に合わせています。

使い方

  1. Android に APK をインストールします。
  2. 音OFF をホーム画面に置きます。
  3. アイコンを押すと、初期設定では 音あり ↔ バイブ を切り替えます。
  4. アイコンを長押しして Settings を開くと、DND の追加や言語変更ができます。
  5. DND を含める場合は、Android の「サイレント モードへのアクセス」を許可してください。
